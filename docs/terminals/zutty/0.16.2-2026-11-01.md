## Known issues found by these records

These are lazarobox issues to fix, not terminal fails, except where a row above says `fail`.

- `Alt+Enter` is dropped: zutty sends `ESC[27;3;13~` (modifyOtherKeys) and crossterm 0.29 cannot parse it. This is the one `fail` row; `Ctrl+J` is the working newline.
- The OSC 52 notice is truncated at 80 columns (tool names lost).
- Focus reports are not forwarded to panes.
- The tool mark 🔧 is an empty box in zutty (no emoji font fallback; zutty/font setup, 2-cell width is kept).
- Model-marks: engine rows in narrow popups lose the engine name (seen in the Kitty run).
- The generic probe key `xterm-256color` is shared by every terminal that sets only that `TERM`, so a stored result may belong to another terminal.
- Harmless: zutty prints `W [vterm.icc:1681] (Unimplemented) attribute: 59` to stderr (SGR 59). Under a tiling WM zutty keeps its 80x24 grid when the window grows (zutty behaviour).
- Not checked: click, copy over SSH, PATH-stripped copy, paste scenarios (pending).
