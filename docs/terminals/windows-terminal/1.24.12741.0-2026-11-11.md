## Known issues found by this record

- `Alt+Enter` is taken by Windows Terminal (fullscreen) and never reaches
  lazarobox. This is terminal configuration, not a lazarobox fail: use
  `Ctrl+J` or unbind the key (see the checklist).
- `Ctrl+]` (`Ctrl+AltGr++` on the es layout) reaches nothing. Only matters
  where `Ctrl+Space` is swallowed, which is not the case in this version.
- The `clip.exe` fallback adds a leading U+FEFF to non-ASCII text. Not seen
  in normal use, where `powershell.exe` is found first.
