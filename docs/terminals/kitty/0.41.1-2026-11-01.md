## Known issues found by these records

These are lazarobox issues to fix, not terminal fails, except where a row above says `fail`.

- Notice truncated at narrow widths: at ~55 columns the OSC 52 notice is cut to `Sent to the terminal` and the hint is lost. Fixed: see the re-test below.
- Focus reports (`ESC[I`/`ESC[O`) are not forwarded to panes (issue #483).
- Model-marks: engine rows in a popup narrower than 62 columns lose the engine name and the codex badge; with `TERM=linux` claude shows `to…`. Fixed in the model-marks PR #485.
- Click was not separately checked (pending); the copy over SSH and PATH-stripped rows are pending (SSH: issue #490). The paste-scenario row was filled by the second round.
- The `install-desktop` picker lists `x-terminal-emulator` as untested even where it was tested (issue #487).
- The chat Conversations list runs typed letters as commands (issue #491, found while testing).
- The generic probe key `xterm-256color` is shared by terminals that set only that `TERM` (issue #489; see the zutty record).
- The tool mark renders as an empty box in zutty (issue #488; see the zutty record).
